# Orpheus Elysium scrolling site

Static one-page website based on the supplied PowerPoint. The 8-page order and image assets follow the deck.

## Preview locally
Open `index.html` or run `python -m http.server 8000` from this folder.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import it in Vercel.
3. Framework preset: Other.
4. Build command: blank; output directory: `.`.
5. Deploy.

No build step is required.
